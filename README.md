# 📋 Gerador de Orçamentos em PDF

Uma ferramenta web simples, moderna e totalmente gratuita voltada para apoiar microempreendedores, trabalhadores autônomos e profissionais informais na profissionalização de seus negócios através da geração rápida de orçamentos estruturados.

> 🎓 **Projeto de Extensão Universitária – UNIP**  
> Este repositório foi desenvolvido como parte das atividades de extensão acadêmica, buscando aplicar o conhecimento técnico de desenvolvimento front-end para gerar um impacto social positivo e direto na comunidade local.

---

## 🚀 Funcionalidades

- **Cadastro Dinâmico:** Interface simples para inserção de dados do prestador e do cliente.
- **Inserção de Itens Flexível:** Adicione ou remova linhas de produtos/serviços conforme a necessidade.
- **Cálculo Automatizado:** O sistema calcula o valor total de cada item (quantidade × valor) e o valor global do orçamento em tempo real.
- **Exportação Limpa para PDF:** Utiliza regras de CSS de impressão para ocultar botões e formulários, gerando um documento timbrado pronto para salvar ou imprimir.

---

## 🛠️ Tecnologias Utilizadas

Para garantir que a aplicação seja leve e acessível em qualquer dispositivo (computador ou celular), utilizamos o desenvolvimento estático sem necessidade de servidores:

| Tecnologia | Função |
| :--- | :--- |
| **HTML5** | Estruturação e semântica de todos os dados e formulários. |
| **Tailwind CSS** | Estilização moderna, responsiva e profissional (via CDN). |
| **JavaScript (ES6+)** | Lógica de cálculo, manipulação dinâmica de itens e controle de impressão. |

## 🌍 Impacto Social e Comunitário

O projeto nasceu da identificação de uma dor real: muitos profissionais autônomos da comunidade (como eletricistas, confeiteiras, técnicos de informática, manicures) perdem credibilidade ou gastam muito tempo gerando orçamentos manuais pelo WhatsApp ou em blocos de papel. 

Ao disponibilizar uma ferramenta que roda direto no navegador, de graça, sem anúncios e sem coletar dados sensíveis em servidores, facilitamos a formalização e a valorização do trabalho desses microempreendedores.

---

## 💻 Como Executar o Projeto

Como o projeto foi centralizado em uma arquitetura de cliente único (Single File), executá-lo é extremamente simples:

1. Faça o clone deste repositório ou baixe o arquivo `index.html`.
2. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador de preferência.
3. Não há necessidade de instalar o Node.js, Docker ou qualquer dependência externa.
